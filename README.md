# Observatório de Trânsito e Clima na Baixada Santista (2022–2025)
Projeto Integrador II - FATEC Baixada Santista

## Como Executar
1. Instale os requisitos:
   pip install fastapi uvicorn duckdb pandas jinja2
2. Inicie a aplicação:
   python iniciar_aplicacao.py
3. Acesse no navegador:
   http://127.0.0.1:8000
